Add LLM Node 1: JD Extractor & Requirement Parser

Parses unstructured Job Description text into structured JSON containing must-have skills, keywords, and seniority.

Node Type: LLM Node
Custom Node ID: node_llm_extract
Model: gpt-4o (Temperature: 0.2)
System Prompt: 
You are an expert Technical Recruiter and ATS parser. Extract key job requirements into strict JSON format with fields: required_skills (array), preferred_skills (array), key_technologies (array), minimum_years_experience (number), and role_summary (string).
User Prompt Template: 
Extract and categorize all requirements from this Job Description:

{{node_trigger_jd.context.job_description}}

Output ONLY a JSON object.
3

Add LLM Node 2: ATS Match Scorer & Gap Analyzer

Compares Master Resume against extracted requirements, outputting a numerical score (0-100) and missing skills list.

Node Type: LLM Node
Custom Node ID: node_llm_score
Model: gpt-4o (Temperature: 0.1)
System Prompt: 
You are an ATS Scoring Engine. Evaluate the candidate's resume against job requirements.
Return JSON with EXACT keys:
- match_score: integer from 0 to 100
- matched_skills: array of string skill matches
- missing_skills: array of string gaps or keywords not explicitly emphasized
- gap_analysis: concise paragraph explaining the score
User Prompt Template: 
Evaluate Candidate Resume:
{{node_trigger_jd.context.master_resume}}

Against Job Requirements:
{{node_llm_extract.output}}

Output strict JSON only.
4

Add the Condition Node: 80% Match Threshold Gate

Controls workflow routing based on the evaluated match_score.

Node Type: Condition Node
Custom Node ID: node_condition_gate
Target Variable: {{node_llm_score.match_score}}
Comparison Operator: >= (Greater Than or Equal)
Target Value: 80
Handle Connection Instructions:
  • Connect the Green "True" Handle on the right to node_output_pass.
  • Connect the Red "False" Handle on the right to node_llm_optimizer.
5

Add LLM Node 3: Google XYZ Formula Resume Optimizer

Activated only when score < 80%. Rewrites bullet points to highlight missing ATS keywords using quantifiable impact statements.

Node Type: LLM Node
Custom Node ID: node_llm_optimizer
Model: claude-3-5-sonnet-20241022 or gpt-4o (Temperature: 0.4)
System Prompt: 
You are an elite Executive Tech Resume Strategist. Rewrite the candidate's bullet points strictly applying Google's XYZ formula: "Accomplished [X] as measured by [Y], by doing [Z]".
Naturally integrate the missing keywords and technical requirements from the JD into the candidate's actual experience without fabricating employment history. Preserve clean Markdown formatting.
User Prompt Template: 
Original Resume:
{{node_trigger_jd.context.master_resume}}

Target Job Requirements:
{{node_llm_extract.output}}

Missing Keywords to Weave In:
{{node_llm_score.missing_skills}}

Generate an ATS-optimized, tailored Markdown resume emphasizing quantifiable engineering impact.

Build Your First Workflow in 5 Steps

Follow this guide to create a Ticket Triage pipeline from scratch

1
Clear or Initialize the Canvas
Click the Trash icon in the header toolbar to start with a blank slate, or click "Templates" to explore ready-made architectures.
2
Drag a Manual Trigger Node
From the left sidebar, drag "Manual Trigger" onto the canvas. Click it to set the seed prompt in the Property Inspector.
3
Add & Connect an LLM Agent Node
Drag an "LLM Agent" node. Click the trigger's right circle handle and drag a connection wire to the LLM node's left circle handle.
4
Configure Prompts with Upstream Variables
In the LLM prompt, type Analyze this customer message: {{node_trigger_1.output}} using the clickable variable chips.
5
Attach an Output Terminal & Click "Run Workflow"
Connect the LLM output to an Output Terminal. Verify the green "DAG Valid" badge and click the blue "Run Workflow" button to watch it execute!
